# 桐灼 GEO 发布节点

这是 GEOFlow 的 Windows 本地发布节点，不是给人工日常打开的开发控制台。

## 使用方式

1. 在 GEO 后台生成配对码。
2. 双击安装包中的 `一键安装发布器.cmd`（也可以使用 `install-desktop.cmd`），无需手动打开 PowerShell。
3. 桌面会生成「桐灼 GEO 发布执行器」快捷方式，双击后静默常驻。
4. 首次绑定时，只需要输入节点名称和后台配对码。
5. 绑定成功后，节点自动心跳、领取任务、打开平台登录窗口并回写结果。

## 客户运行方式

```powershell
双击 `一键安装发布器.cmd` 即可。
```

日常使用不需要打开本地网页或命令行。后台的「发布设备 / 发布助手」页面负责查看在线状态、平台会话、任务进度和失败原因。

## 实施诊断方式

- 健康检查：`http://127.0.0.1:18280/healthz`
- 诊断页面：`http://127.0.0.1:18280`
- 支持包：在诊断页面导出，或调用本地支持包接口。

这些入口只给实施和售后排查使用，不作为客户日常发布入口。

## 说明

- 节点会把平台登录态保存在本机 Profile 中。
- 后台只记录设备状态、平台会话和任务结果。
- 不上传平台密码、Cookie、验证码或浏览器 Profile。
- 支持导出诊断包，便于售后排查。
## Windows 桌面版

本项目现在同时提供真正的 Windows 桌面客户端。桌面客户端由 Electron 窗口承载本地发布服务，支持独立窗口、系统托盘、单实例运行和开机后继续运行；客户日常不需要打开 localhost 页面。

生成安装包：

```powershell
npm.cmd run build:desktop
```

安装包输出在 `release/tongzhuo-geo-publisher-setup-1.8.14-x64.exe`，安装后会创建桌面快捷方式和开始菜单入口。安装包已内置发布浏览器运行时，客户电脑无需单独安装 Microsoft Edge。账号组、平台 Profile 和登录态写入 Electron 的用户数据目录，安装包不包含客户账号数据。
