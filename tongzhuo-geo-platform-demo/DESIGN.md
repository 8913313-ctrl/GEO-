# 官网主题与图文设计记录

## 设计方向

官网不是单一颜色皮肤，而是由同一套企业 CMS 数据驱动的九套独立页面编排。主题切换只改变展示层，不修改企业身份、产品、文章、栏目或发布记录。桐灼原有的“数字身份证 / 护照”视觉保留为内部原版主题，不会被客户行业主题覆盖。

## 主题结构

- professional：编辑档案式首页，强调企业身份、证据和窄栏阅读。
- industrial：规格表与工程材料式首页，服务按规格/应用纵向展开，案例使用高密度证据网格。
- energy：控制室式首页，可靠性、选型和技术资料使用信号列表与双列信息块。
- beauty：杂志式首页，使用大图、分栏产品单元和更长的阅读行距。
- engineering-case：项目实录式首页，案例优先，按场景、过程和结果组织。
- product-matrix：产品目录式首页，产品线以矩阵网格呈现，文章作为选型知识入口。
- space-materials：空间材料档案式整站。双层资料表头、左右展开的空间主视觉、材料系列索引、工程项目画廊、空间期刊列表和沉浸阅读文章页；适用于瓷砖、建材、灯具与空间材料企业。
- power-systems：UPS / 数据中心工况控制台式整站。系统状态栏、设备工况首屏、选型入口、技术手册列表、参数化文章阅读和技术支持页；适用于关键电源、机房和工业技术设备企业。
- supply-chain：物流 / 供应链服务分流式整站。业务咨询栏、服务入口导航、分流首屏、服务网络、行业路线、调度式资讯列表和路线阅读页；适用于物流、仓储、运输和供应链服务企业。

九套主题的首页、服务、案例、问题地图、关于、联系、资讯列表和文章详情均有各自的页面结构，而非只依赖 CSS 颜色。新行业主题保留同一套企业数据边界，但各自拥有独立页头、页尾、行动按钮和阅读路径。

## 行业主题响应式规则

- 空间材料：桌面使用双层档案表头；移动端折叠为纸张色导航抽屉，首屏由双栏改为连续的资料与图片流。
- UPS / 数据中心：桌面保留状态行与六项技术导航；移动端只保留品牌和工况菜单，并以深色技术抽屉承接全部入口。
- 物流 / 供应链：桌面保留业务咨询行与服务导航；移动端使用浅色服务抽屉，首屏服务分流面板跟随主视觉转为纵向阅读。

在 390px 宽度下，三个行业主题的菜单按钮、展开抽屉和正文均不产生横向溢出。菜单使用现有 `site.js` 的打开、关闭、Esc 退出和链接跳转后关闭行为。

## 图文规则

文章生成后，从当前企业知识范围内已审核、来源明确的图片中按标题、主题词、业务线、图片名称、替代文本、说明和标签打分。第一张作为封面，后续图片插入相关正文段落；匹配状态、分数、理由、来源和替代文本记录在 `article.imagePlan` 中。

没有合适图片时标记缺图并继续生成正文。封面、正文图片和 metadata 会随正式内容版本同步，在官网卡片、列表、文章详情、Open Graph、Twitter Card 与 Article JSON-LD 中使用。

## 交互与可访问性

图片始终有替代文本和说明；主题首页保留明确 CTA；列表和文章在移动端不产生横向溢出。自动配图失败是可见状态，不是阻断式错误。
