# 桐灼 GEO 私有化交付版本说明

## 1.0.0-alpha.1

这是单企业私有化交付基线，面向“一家企业、一套服务器环境”的部署方式，不包含 SaaS 多租户和在线计费能力。

本版本交付范围：

- 企业内部账号、角色、权限、会话、CSRF 防护和审计日志；
- 业务线、关键词、问题、选题、计划、写作智能体、文章生产与人工审核；
- 模型供应商配置、API Key 加密保存、真实模型调用和失败留痕；
- 企业知识库、版本审核、分块、向量/关键词混合检索、RAG 引用追溯；
- 官网 CMS、文章审核后发布/下线、栏目、Sitemap、RSS、robots.txt 和 llms.txt；
- 本地发布助手配对、账号状态同步、发布任务和结果回写；
- 基于仓库方法的 GEO 效果监测基础能力；
- Docker Compose 生产架构、HTTPS 后台入口、备份恢复、升级回滚与自动验收；
- `blank` 通用空白包和 `migrated` 客户迁移包两种交付模式。

交付边界：

- 交付包不代替客户购买模型、OCR、向量数据库、域名和 HTTPS 证书；
- 各内容平台的自动发布能力受平台登录策略、验证码和页面变更影响；
- GEO 监测结果是按既定问题集和采样时点形成的可复核观测，不代表模型厂商承诺；
- `migrated` 包含客户数据和恢复密钥，压缩格式本身不提供加密，必须通过受控加密通道传输。

升级前必须执行完整备份，并通过备份校验；候选镜像使用隔离 Compose 项目预构建，不覆盖运行中的正式镜像标签；升级后须运行 `operations/verify.sh` 核对事务标记、Compose 配置来源和运行镜像 ID。自动失败回滚会恢复升级事务绑定的 backup v2；任何人工回滚都要求当前状态安全备份成功，默认保留当前数据库，只有明确传入 `--restore-pre-upgrade-data` 时才覆盖当前数据。
