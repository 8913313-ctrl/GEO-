# UI 按钮位审计报告（2026-08-25）

> 哥哥让我做的「应该有按钮/不该有按钮/缺哪里」专项审查。本轮**只判断不动手**，每条结论附判断逻辑 + 推荐处理。
> 数据基线：`tools/ui-baseline.json`；任务书：`docs/UI-FIX-TASKS.md`

## 判断方法（透明可复跑）

| 类型 | 判断依据 | 数据来源 |
|---|---|---|
| **该有却没（死按钮/丢失）** | 三方对比（A 代码注册 vs B 模板渲染 vs C 实际可见） | `tools/ui-audit.mjs --check` |
| **空态该不该有 CTA** | 横向对比同类型空态 + 页面顶部是否已有入口 | 静态扫描 + 浏览器评估 |
| **表格该不该有操作列** | 表头是否有"操作/动作/管理"列 + 数据行是否有内联操作 | 浏览器扫描 + 模板代码 |
| **不该有多余按钮** | 重复入口 / 同功能多版本 / 装饰性空按钮 | 模板扫描 + 上下文定位 |
