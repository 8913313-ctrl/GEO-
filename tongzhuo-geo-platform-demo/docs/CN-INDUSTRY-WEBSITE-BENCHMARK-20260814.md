# 国内行业官网案例与模板基准

> 目的：为企业源码部署版建立少量、按行业与业务形态区分的完整官网模板。
>
> 这些案例仅用于研究信息组织、视觉密度与交互方式，不复制其品牌、文案、图片或代码。正式站只能使用部署企业已审核、来源可追溯的素材。

## 已验证案例

| 行业/细分 | 国内案例 | 已观察到的结构与动效 | 可吸收的原则 |
| --- | --- | --- | --- |
| 科技/企业数字化 | 华为企业业务 `e.huawei.com/cn` | 首屏 Swiper 淡入轮播、案例横向轮播、活动轮播；方案、产品、案例、购买支持分层 | 首屏只服务一个当前主题；案例与行业方案是主内容，不是底部装饰卡片 |
| 科技/集团品牌 | 金山 `kingsoft.com` | 全幅静音循环品牌视频；极少导航与内容干扰 | 面向品牌/集团型科技企业可使用视频叙事，但必须有海报图和无动画降级 |
| 制造/集团多业务 | 美的 `midea.com/cn` | 建筑主视觉；业务板块入口；文字分段入场；数据快览 | 多业务集团应先展示业务地图，再进入各业务官网，不套 SKU 筛选页 |
| 医疗器械/生命科技 | 迈瑞 `mindray.com/cn` | 5 秒自动轮播、真实医疗服务场景、新闻与客户故事、产品生态导航 | 医疗首屏使用真实临床/服务场景，内容以产品、解决方案、用户服务、资料支持组织 |
| 物流/供应链 | 顺丰 `sf-express.com/chn/sc` | 4 秒轮播、个人/企业服务分流、行业解决方案、右侧固定客服/合作入口 | 物流官网的第一件事是让访客进入寄件、查询或企业方案，而不是先读品牌介绍 |
| UPS/数据中心 | 科士达 `kstar.com.cn` | 静音品牌视频首屏、8.5 秒淡入轮播、产品超菜单、固定在线需求表 | UPS/电气设备要用真实机房、设备与应用场景；产品中心、方案、案例、下载支持组成完整路径 |
| 瓷砖/建材 | 欧神诺 `oceano.com.cn` | 3 秒图文轮播、产品/家装顾问/门店加盟/工程案例并列；内容和材质视觉强 | 瓷砖建材以空间、材质、系列、应用与门店/设计服务为核心，不能做成 UPS 式目录页 |
| 照明 | 雷士照明 `nvc-lighting.com.cn` | 专业/消费/智能照明三级产品分类；1200ms 产品横移；点亮前后视频素材 | 照明模板要把项目空间、光效、产品线和下载资料放在同一条路径上 |
| 文旅/酒店集团 | 华住 `hworld.com` | 全幅静音循环视频、5 秒品牌轮播、酒店品牌横向轮播、固定二级品牌导航 | 文旅/空间官网先卖体验和目的地，再提供品牌/空间/合作入口；不是商品筛选页 |
| 文旅演艺/目的地 | 宋城 `songcn.com` | 演艺作品、景区、酒店按目的地与内容组合；大量横向轮播 | 有内容 IP 的文旅企业应以演出/目的地故事组织，不套酒店预订站结构 |

## 模板库：建议保留 9 个完整官网包

每个官网包均包含：首页、核心业务页、解决方案/应用页、案例页、文章/资讯页、联系/咨询页。

| 行业 | 模板包 | 首页主角 | 首要动作 | 关键页面 |
| --- | --- | --- | --- | --- |
| 科技 | 企业数字化/平台型 | 真实产品界面或业务现场 + 当前方案 | 查看方案 / 联系专家 | 平台能力、行业方案、客户故事、资源中心 |
| 科技 | 集团/品牌叙事型 | 静音循环品牌影片或企业现场 | 认识业务 / 观看品牌影片 | 业务地图、新闻、人才、可持续发展 |
| 制造 | 多业务集团型 | 总部/工厂/产品制造场景 | 进入业务板块 | 业务地图、技术研发、制造基地、新闻 |
| 建材 | 瓷砖/岩板空间型 | 完整空间摄影或材质近景 | 查看产品系列 / 寻找门店 | 产品系列、空间灵感、工程案例、设计服务、门店 |
| 照明 | 项目照明方案型 | 有灯光效果的商业/酒店/公共空间 | 按空间找方案 | 应用空间、产品线、项目案例、下载与服务 |
| 电气设备 | UPS/数据中心型 | 机房、设备、控制柜或能源场景 | 提交工况 / 进入选型 | 产品中心、解决方案、项目案例、技术下载、服务网点 |
| 医疗 | 器械/生命科技型 | 经授权的临床、设备或服务场景 | 产品与解决方案 | 临床与质量、用户服务、资料中心、专业联系 |
| 物流 | 物流/供应链型 | 运输、仓配、交付或货物场景 | 寄件/查件/提交企业需求 | 服务分流、行业方案、网络能力、合作咨询 |
| 文旅空间 | 酒店/目的地/空间体验型 | 沉浸空间视频或目的地摄影 | 探索体验 / 咨询预订 | 品牌故事、空间服务、目的地/活动、旅行内容、合作联系 |

## 动效规范：只保留会帮助理解和操作的动效

| 模块 | 行为 | 参数基线 | 降级 |
| --- | --- | --- | --- |
| 首屏轮播 | 图文整体切换，支持箭头、圆点和暂停 | `800ms` 过渡；自动 `5-8.5s`；鼠标或触摸操作后不强制跳回 | `prefers-reduced-motion` 时停止自动播放，只保留手动切换 |
| 首屏视频 | 静音、循环、有首帧海报图；仅作为场景氛围 | 视频不可成为唯一信息来源；文本和 CTA 始终位于语义 HTML | 减少动态偏好或弱网时显示海报图 |
| 导航 | 桌面端二级菜单 150-220ms 淡入和位移；移动端抽屉菜单 | 使用 `transform` 和 `opacity`，不做高度抖动 | 直接显示/隐藏，焦点被约束在抽屉内 |
| 产品/案例 | 横移或渐入展示系列、空间案例和项目卡 | 300-800ms；只在用户触发或区域进入后执行一次 | 列表直接呈现，不能隐藏内容 |
| 固定动作 | UPS/物流等高意图行业提供“提交需求/在线咨询”固定入口 | 44px 最小触达区；只保留一个主要动作 | 移动端放入底部固定栏，不遮挡正文 |
| 数字/数据 | 只对已核验的统计数据执行一次计数 | 600-900ms；必须能读到静态最终值 | 直接显示最终值 |

## 明确不做

- 不把所有行业放进同一套“产品矩阵 + 三卡片”骨架。
- 不用抽象色块或生成图冒充客户工厂、医院、酒店、项目或人员。
- 不预填客户名称、项目数量、认证、疗效、覆盖范围或经营数据。
- 不让动效阻断内容阅读、键盘操作、移动端性能或搜索引擎抓取。

## 下一步审核顺序

1. 先基于上表制作 3 张高保真审核图：`瓷砖/空间`、`UPS/数据中心`、`物流/供应链`。这三张最能验证制造业已经真正细分。
2. 用户确认这三张的方向后，再制作 `科技平台`、`医疗器械`、`文旅空间` 审核图。
3. 每张通过后，再开发对应完整页面包，而不是只实现首页。
